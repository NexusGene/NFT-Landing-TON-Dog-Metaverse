# NFT Landing TON Dog Metaverse - Диагностический отчет

## Обзор проекта

**Название проекта:** NFT Landing TON Dog Metaverse  
**Тип проекта:** Статический веб-сайт (лендинг страница)  
**Основная цель:** Промо-сайт для NFT коллекции Metaverse Dog на блокчейне TON  
**Дата анализа:** Сентябрь 2025  

## Техническая архитектура

### Структура проекта
```
📦 NFT-Landing-TON-Dog-Metaverse/
├── 📄 index.html (44KB) - Главная страница
├── 📁 css/
│   ├── style.css (164KB) - Основные стили
│   └── style.min.css (48KB) - Минифицированные стили
├── 📁 js/
│   ├── app.js (96KB) - Основной JavaScript
│   └── app.min.js (188KB) - Минифицированный JavaScript
├── 📁 img/ (3.6MB) - Графические ресурсы
├── 📁 fonts/ - Веб-шрифты
└── 📄 Various favicons и PWA манифест
```

### Технологический стек
- **Frontend:** Чистый HTML5, CSS3, Vanilla JavaScript
- **Фреймворки:** Без использования фреймворков (vanilla approach)
- **Библиотеки:** 
  - Swiper.js (для слайдеров)
  - Собственная система модулей
- **Шрифты:** Akshar, Roboto (локально размещённые)
- **Оптимизация:** WebP поддержка, минификация файлов
